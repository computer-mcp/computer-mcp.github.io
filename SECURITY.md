# Security policy

This repository contains only the public static website. For a vulnerability in the Computer MCP
App, gateway, transports, policy, workspace containment, Codex integration, or release artifacts,
use
[private vulnerability reporting](https://github.com/computer-mcp/computer-mcp/security/advisories/new)
in the main repository.

For a website-only issue that does not disclose a vulnerability, open an issue in this repository
after it is published. Do not include credentials, private workspace data, local paths, or private
tool output.
