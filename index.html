了解安全模型

观察，或控制

观察模式只允许查看，不修改系统。控制模式下，受限访问只使用你选择的工具、项目和集成，不能任意执行命令。完全访问需要你为已连接的客户端明确批准。

完全访问，默认仅本次会话

完全访问可以执行命令，访问当前 macOS 用户可用的资源；工作区不是沙箱。授权默认仅本次会话，“始终允许此客户端”需单独选择。会话内的普通本机操作和已验证官方插件更新无需重复批准。新账号、未验证的持久插件与 macOS 隐私权限仍需各自授权。

Codex 保留原生执行设置

插件通过 swift-codex 提供 App Server 与 Exec 生命周期。Codex 管理自己的配置、provider、MCP、Skills、hooks 和认证。未覆盖的执行参数遵循本机 Codex 配置，包括原生 Full Access；显式覆盖遵循原生语义。原生审批保留自己的决定和作用域，不能批准宿主票据。

Computer MCP、OpenAI Dots 与 Codex Remote 可以互相配合。

Computer MCP

从 ChatGPT 或兼容 MCP 的客户端直接组合使用受治理的通用本机能力。

连接独立宿主，选择对应工作区。调用普通工具不要求启动 Codex 任务。

OpenAI Dots

带记忆、应用和主动工作的常驻云端 Agent，拥有自己的云端电脑。

一个 Dot 同时连接一台个人电脑，可以委派本地 ChatGPT Work 或 Codex 任务。

Codex Remote

第一方远程编程：启动或继续 Codex 任务、跟进、审批操作并审查 Diff 和测试结果。

在已连接的多台电脑间切换，由选定的宿主执行 Codex 任务。

客户端与服务用量条款仍然适用。OpenAI 表示 Dot 对话不计入 ChatGPT 用量限制，委派的 Codex 与 ChatGPT Work 任务按各自的正常限制计量。

连接前，你可能想知道。

所有 CLI 都能直接用吗？

先安装外部工具，再注册命令或安装兼容插件。CLI Tree 描述命令、参数与结构化覆盖范围。Computer MCP 不负责安装厂商运行时，也不会自动把任意可执行文件变成完整集成。

CLI Tree 参考
这些能力都是内置的吗？

Gateway 提供共同的接入与权限层。插件打包 MCP、CLI 和 Skills，新安装默认停用，也不自动授予权限。Codex 需要对应插件和本机配置，高级编排仍是实验能力。

查看能力状态
可以操作桌面应用吗？

Computer Use 插件接入原生 CUA，原生 Accessibility 工具提供兜底。实际可用性取决于具体操作、macOS 隐私授权与厂商调用者认证；能列出工具不代表已获得桌面控制能力。

Computer Use 插件
和 Codex Remote 有什么关系？

普通的远程 Codex 控制，优先使用官方原生体验。Computer MCP 适合还需要本机 CLI、MCP 服务、文件和 Skills，并希望跨兼容客户端组合这些能力的工作流。

实际执行有哪些边界？

工作目录和 worktree 不是操作系统沙箱。宿主完全访问与 Codex 原生 Full Access 使用执行用户的权限。取消请求不代表完成或清理已确认；结果不明的写入不会自动重放。Gateway 不能停止不归自己所有的外部 Codex 客户端。
